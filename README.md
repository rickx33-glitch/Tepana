# Tepana | Gestor de tareas laborales

**Tepana** es una aplicación web diseñada para organizar y administrar pendientes laborales de manera sencilla, visual e intuitiva.

El proyecto fue desarrollado utilizando HTML5, CSS3 y JavaScript, aplicando conceptos de programación orientada a objetos, manipulación del DOM y almacenamiento local mediante LocalStorage.

## Características principales

- **Agregar tareas:** registrar nuevos pendientes laborales.
- **Editar tareas:** modificar la descripción de las tareas existentes.
- **Completar tareas:** cambiar el estado de una tarea entre pendiente y completada.
- **Eliminar tareas:** quitar tareas de la lista.
- **Contadores dinámicos:** visualizar el total de tareas, las pendientes y las completadas.
- **Almacenamiento local:** conservar las tareas incluso después de cerrar o actualizar la página.
- **Diseño responsivo:** adaptar la interfaz a computadoras, tabletas y teléfonos móviles.

## Programación orientada a objetos

El proyecto utiliza dos clases principales:

- **Tarea:** representa cada pendiente e incluye su identificador, nombre y estado de finalización.
- **GestorDeTareas:** administra las operaciones de creación, edición, eliminación, actualización y visualización de las tareas.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html`.
4. Ejecutar la aplicación mediante la extensión Live Server.
5. Utilizar el gestor de tareas desde el navegador.

No requiere una base de datos externa ni un servidor backend para su funcionamiento actual.

Desarrollar una aplicación web funcional que permita aplicar conocimientos fundamentales de desarrollo frontend, JavaScript moderno, programación orientada a objetos, manipulación del DOM y almacenamiento de información en el navegador.
